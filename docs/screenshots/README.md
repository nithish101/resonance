# Screenshots

Everything in this folder is generated by `pnpm capture` (`scripts/capture.mjs`). Nothing is
hand-edited.

| File                                 | How it's made                                                                                                                                                                                                                |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `tunnel-*.png`, `hero.gif`           | Deterministic capture mode (RD-11): `Deep House Soul` decoded and analysed offline, frames rendered at fixed audio times. Same input, same pixels. The GIF is 10 s at 15 fps with grain off (grain defeats GIF compression). |
| `picker.png`, `photosensitivity.png` | The live app on first load.                                                                                                                                                                                                  |
| `debug-overlay.png`, `settings.png`  | The live app playing `Deep House Soul`. Overlay numbers are real readings from the machine that ran the script.                                                                                                              |
| `fallback-banner.png`                | The live app with `?renderer=main&coi=0`, forcing main-thread rendering and the postMessage transport.                                                                                                                       |

All of it renders with SwiftShader (software WebGL2) under headless Chromium, so FPS in the
overlay screenshot reflects a CPU rasterizer at 1440x900, not GPU performance. GPU numbers are
in [benchmarks.md](../benchmarks.md).
