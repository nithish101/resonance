# Beat annotations

Hand-made ground truth for the bundled songs, used by `pnpm eval`. One file per track,
`<track-id>.beats`, with one beat time in seconds per line.

## Making one (about 10 minutes per song)

1. `pnpm dev`, then open http://localhost:5173/annotate.html. Use wired headphones or speakers;
   Bluetooth adds delay the browser can't see.
2. **Calibrate:** tap Space along with the 120 BPM click track. The median offset is your tap
   latency, subtracted from everything you tap afterwards.
3. Pick the track and tap Space on every beat through **Pass 1**, then again through **Pass 2**.
4. **Download.** Taps that both passes agree on (within 100 ms) are averaged, corrected, and
   saved. Move the file here as `<track-id>.beats` and run `pnpm eval`.

Annotations are never generated by Resonance's own detector, which would make the evaluation
circular. Taps are timed against the audio output clock (`getOutputTimestamp`), not wall time.
