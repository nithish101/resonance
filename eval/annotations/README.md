# Beat annotations

Hand-made ground truth for the bundled songs, used by `pnpm eval`. One file per track,
`<track-id>.beats`, with one beat time in seconds per line.

Annotations come from a person tapping along (the tap tool arrives with milestone 12): two passes
per song, averaged, corrected for the tapper's measured latency. They are never generated by
Resonance's own detector, which would make the evaluation circular.

None exist yet, so `docs/evaluation.md` reports the real songs as "not annotated yet".
